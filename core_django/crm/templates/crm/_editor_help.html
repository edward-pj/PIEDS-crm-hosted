Links

Select the words you want clickable and press Insert link, or type the syntax yourself:

[book a call](https://cal.com/you)

The recipient sees book a call as a link. This works whether or not HTML is on. Mail goes out as HTML with a plain-text fallback, so clients that block HTML still get the URL in brackets.

HTML

Tick {{ html_label }} to write your own markup — a signature, a divider, inline styling. Paste the signature you already use:

<strong>Anushreya</strong><br>
<span style="color:#555">PIEDS, BITS Pilani</span><br>
<a href="mailto:you@pilani.bits-pilani.ac.in">Email</a>

With it on, you control line breaks — write <br> or <p>, because blank lines no longer become spacing on their own. Leave it off and your {{ what }} is ordinary text: every tag shows up as literal <tags> in the recipient's inbox.

Images

Needs HTML on. The image has to be somewhere public on the web — a mail has no page to be relative to, so logo.png resolves for nobody:

<img src="https://pieds.in/logo.png" alt="PIEDS" width="120">

What gets refused

<script>, onclick= and friends, <iframe>, <form>, <style> sheets, and any link that is not http, https, mailto or tel. Every mail client strips these, so allowing them would only let this preview show you something no recipient ever sees.
